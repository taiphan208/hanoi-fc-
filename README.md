# Hanoi Warriors FC – Website câu lạc bộ bóng đá

Bài tập lớn A3 học phần **FIT4014 – Thiết kế web và triển khai hệ thống phần mềm**, Trường Đại học Đại Nam.

## Công nghệ và phạm vi

- HTML5 ngữ nghĩa.
- CSS3 thuần: Flexbox, CSS Grid và Media Queries.
- Không sử dụng Java, JavaScript, framework hoặc backend.
- Biểu mẫu liên hệ dùng kiểm tra tích hợp của HTML5 (`required`, `type="email"`, `minlength`, `maxlength`).
- GitHub Pages dùng để xuất bản website tĩnh.

## Các trang

- `index.html` – Trang chủ và giới thiệu câu lạc bộ.
- `schedule.html` – Lịch thi đấu và kết quả minh họa.
- `squad.html` – Đội hình cầu thủ giả lập theo vị trí.
- `contact.html` – Thông tin liên hệ và biểu mẫu HTML5.
- `css/style.css` – Giao diện dùng chung và bố cục responsive.
- `assets/images/` – Vị trí lưu hình ảnh của dự án.

## Chạy website trên máy tính

Mở `index.html` bằng trình duyệt. Không cần cài máy chủ hoặc thư viện ngoài.

## Responsive

Các breakpoint CSS chính: 960px, 720px và 500px. Có thể kiểm tra thêm tại các chiều rộng 320px, 375px, 430px, 768px, 960px và 1366px.

## Triển khai GitHub Pages

1. Đưa nội dung thư mục dự án lên nhánh `main` của repository.
2. Mở **Settings → Pages**.
3. Chọn **Deploy from a branch**, nhánh `main`, thư mục `/(root)`.
4. Lưu cấu hình và chờ GitHub Pages triển khai.
5. Mở URL Pages để kiểm tra trang chủ, các trang con và stylesheet.
